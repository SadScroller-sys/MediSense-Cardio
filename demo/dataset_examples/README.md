# Dataset pictures for the demo

Simulated phone photos made from PTB-XL recordings (set N); NOT real phone photos. They are the demo's example pictures. After a check the app shows the true answer from the dataset labels next to what the tool said (the file name starts with the page id, for example N037). `KEY.csv` lists the true answers of these examples. **All 120 pictures** are in `results/paper_n/N_sim/photos/`; any of them can be uploaded by hand, and the tab 'Dataset gallery (instant results)' lists every one.
